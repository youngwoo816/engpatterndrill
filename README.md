# Rep English — 영어 회화 패턴 반복 훈련

일상 대화 · 여행 영어 · 비즈니스 영어(회의/이메일/업무) 3개 카테고리, 총 1,552문장(예문 1,940문장 별도)을 원어민이 실제로 말하는 구어체로 패턴 단위로 반복 훈련하는 모바일용 웹페이지입니다.

| 카테고리 | 패턴 | 문장 |
|---|---|---|
| 일상 대화 (+ 일상 문제 상황) | 66 | 528 |
| 여행 영어 (공항·호텔·식당·교통·쇼핑·관광·긴급 + 문제 상황 대처) | 65 | 520 |
| 비즈니스 영어 (회의·이메일·업무 + 업무 문제 상황) | 63 | 504 |

## 한 문장 학습 구조
1. **듣기** — 패턴(밑줄)과 뜻 확인, 미국/영국 발음으로 듣기 · 천천히 듣기
2. **따라 말하기 ×2** — 전체 문장 → 단어 절반을 가린 문장 순서로 따라 말하기
3. **조립** — 섞인 단어를 순서대로 눌러 문장 완성
4. **바꿔 말하기** (패턴마다 1번) — 주어·명사·동사 자리를 골라 바꿔 새 문장 3개 이상 만들어 말하기. 한국어 뜻도 함께 바뀜
5. **회상** — 한국어만 보고 영어로 말하기/입력 → 일치도 채점 → 자기 평가(다시/애매/완벽)

학습 중 상단의 **목록 · 이전 문장 · 다음 문장 · 다음 패턴** 버튼으로 자유롭게 이동할 수 있습니다.
하루 분량(1~50문장, 1개 단위 조절)만큼 새 문장을 마치면 그날이 **Day N 완료**로 기록됩니다.
채점 결과는 간격 반복(1·2·4·7·15·30·60일)으로 **복습** 큐에 들어갑니다.

## 발음
- 설정 또는 학습 화면의 발음 버튼으로 **미국 발음 / 영국 발음** 전환
- 기기에 설치된 음성 중 기계음(Zarvox, Fred, eSpeak 등 노벨티·합성 음성)은 목록에서 제외하고, 자연스러운 음성(Natural·Enhanced·Siri·Google 등)을 우선 선택
- 실제 음질은 기기·브라우저에 설치된 음성에 따라 다릅니다 (iPhone: 설정 → 손쉬운 사용 → 읽기 및 말하기 → 음성에서 고품질 영어 음성 추가 가능)

## 화면
- **예문**: 패턴마다 형태가 다른 예문 10개(긍정·부정·의문·과거·주어 변화·응답 등, 총 1,740문장). 10개 전체 듣기, 영어/한국어 가리기, 이전·다음 패턴, 학습 화면에서도 바로 열기
- **학습**: 카테고리별 Day 시작, 오늘 완료 여부, 복습 대기 문장
- **진척도**: 연속 학습일, 16주 학습 기록 히트맵, 카테고리별 Day 지도, 섹션별 진행률, 완료한 Day 기록
- **문장 목록**: 전체 패턴·문장 검색, 문장별 듣기
- **설정**: 하루 분량(1~50문장), 화면 모드(기기 설정/라이트/다크, 상단 버튼으로도 전환), 발음(미국/영국), 목소리, 속도, 자동 재생, 진도 백업/복원

진도는 각 사용자의 브라우저(localStorage)에 저장되므로 링크를 여러 사람에게 공유해도 서로 섞이지 않습니다.

## 배포 (GitHub Pages)
1. 저장소 **Settings → Pages**
2. **Source: Deploy from a branch**, Branch: `main` / `/ (root)` 선택 후 Save
3. 1~2분 뒤 `https://<사용자명>.github.io/engpatterndrill/` 로 접속

> `index.html`을 파일로 직접 열면(file://) 문장 데이터를 불러오지 못합니다. 로컬 확인은 `python3 -m http.server` 후 `http://localhost:8000` 접속.

## 문장 추가 방법
`data/*.txt` 형식:
```
# 섹션 이름
## 패턴 | 뜻 | 팁(선택)
English sentence. | 한국어 해석
```
예문 10개 데이터는 `data/forms-*.txt`에 `@패턴번호` 줄 다음 `형태 | 영어 | 한국어` 형식으로 들어 있습니다.

바꿔 말하기 데이터는 `data/swap-*.txt`에 `패턴번호 | 영어 틀 | 한국어 틀 | 라벨: 영어=한국어 / ... ;; 라벨: ...` 형식으로 들어 있습니다.

문장 ID는 파일 내 순서로 매겨지므로 **기존 문장 사이에 끼워 넣지 말고 파일 끝에 추가**해야 기존 사용자의 진도가 유지됩니다.

## 2차 개선 (v2)
| 항목 | 내용 |
|---|---|
| 진척도 2단계 | 학습함(한 번 이상 학습) / 익힘(복습에서 '완벽' 1회 이상)으로 나눠 표시 |
| 하루 마무리 복습 | Day 목표 달성 직후 오늘 배운 문장을 한국어→영어로 한 번 더 떠올리기 (시간 제한 없음, 건너뛰기 가능) |
| 조립 힌트 제거 | 첫 단어 대문자·마지막 문장부호를 숨겨 순서가 드러나지 않게 함 |
| 받아쓰기 복습 | 복습 방식: 섞어서 / 한→영 / 받아쓰기 선택 |
| 예문 읽음 기록 | 패턴별 "10개 다 읽었어요" 또는 전체 듣기 완료 시 자동 표시, 진척도에 반영 |
| 복습 상한 | 하루 복습 개수 상한(기본 20), 밀린 문장은 오래된 순 |
| 빠른 모드 | 듣기·따라 말하기·회상만 진행 (문장당 약 1분), 남은 문장 예상 시간 표시 |
| 첫 방문 안내 | 3장 안내, 설정에서 다시 보기 |
| Day 지도 | 실제 완료 기록 + 남은 예상 Day로 표시 |
| 연속 학습일 | Day 완료 또는 복습 완료한 날 모두 인정 |
| 채점 완화 | 숫자↔영어 숫자, p.m./pm, 하이픈, 영국식 철자, OK/okay 동일 처리 |
| 학습 알림 | 설정 → 학습 알림에서 시간·요일 지정. 캘린더 알림(구글 캘린더 링크, .ics 파일)은 바로 동작하고, 푸시 알림은 알림 서버(Cloudflare 워커, `push/SETUP.md`) 연결 후 사용. 그날 Day를 마치면 알림을 건너뜀 |
| 발음 점수 (보류) | 음성 인식 기반 단어 단위 점수 코드는 남겨 두고 화면에서는 숨김 (`PRON_ENABLED = false`) |
| 녹음 비교 | 따라 말하기·정답 화면에서 내 발음 녹음 → 원어민과 번갈아 듣기 (마이크 권한 필요, GitHub Pages 주소에서 동작) |
| 홈 화면 설치(PWA) | 앱 아이콘, 오프라인 실행, 홈 화면 추가 안내 |
| 백업 알림 | 학습 20문장 이상 & 마지막 백업 7일 경과 시 홈에 알림 |

## 롤백 방법
- **전체 되돌리기 (v1 상태로):** 개선 전 버전은 `backup/v1.0-stable` 브랜치(커밋 `8f3b376`)에 보관되어 있습니다.
  GitHub에서 Pages 배포 브랜치를 `backup/v1.0-stable`로 바꾸면 즉시 이전 버전으로 서비스됩니다.
  (Settings → Pages → Branch: `backup/v1.0-stable` → Save)
- **기능 하나만 되돌리기:** 기능마다 커밋이 나뉘어 있어 해당 커밋만 `git revert <커밋>`으로 취소할 수 있습니다.
- 학습 기록(브라우저 저장)은 v1·v2가 같은 형식을 쓰므로 롤백해도 사라지지 않습니다.

## 관리자 페이지 (학습자 진도 모아 보기)
- 주소: `admin.html` (앱 화면에는 링크 없음) · 관리자 키를 아는 사람만 조회 가능
- 서버: Cloudflare 워커 하나(`push/worker.js`)가 학습 알림 · 자동 백업 · 관리자 조회를 모두 처리 (무료 플랜)
- 설정 방법: 서버 [`push/SETUP.md`](push/SETUP.md) · 관리자 키 [`admin/SETUP.md`](admin/SETUP.md)
- `config.js`의 `serverUrl`이 비어 있으면 서버 기능은 꺼지고 앱은 기록을 그 기기에만 저장합니다.

## 자동 백업 · 기기 옮기기
- 서버가 연결돼 있으면 학습 기록이 자동 저장됩니다 (최대 10분에 한 번, Day 완료 시 즉시).
- 설정 → 백업의 **복구 코드**로 다른 기기나 iPhone 홈 화면 앱에서 기록을 불러옵니다.
- 서버 없이 쓰는 **수동 백업 코드**도 그대로 있습니다.
