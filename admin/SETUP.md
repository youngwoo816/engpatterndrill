# 관리자 페이지 설정 (약 3분)

학습자 진도는 학습 알림과 같은 **Cloudflare 워커(`rep-english`)** 에 저장됩니다.
워커가 이미 배포돼 있다면 **관리자 키 하나만 추가**하면 됩니다. (워커 설치는 `push/SETUP.md`)

## 1. 관리자 키 넣기
1. Cloudflare 대시보드 → **Workers 및 Pages → rep-english → 설정**
2. **변수 및 비밀 (Variables and Secrets) → 추가**
   - 유형: **비밀 (Secret)** ← 반드시 비밀로 (값이 화면에 다시 보이지 않음)
   - 이름: `ADMIN_KEY`
   - 값: 나만 아는 긴 문자열 (영문+숫자 20자 이상 권장)
3. **배포 / 저장**

> 관리자 키는 저장소, 채팅, `config.js` 어디에도 적지 마세요.

## 2. 관리자 페이지 열기
- 주소: `https://youngwoo816.github.io/engpatterndrill/admin.html` (앱 화면 어디에도 링크하지 않았습니다)
- 서버 주소는 자동으로 채워집니다. **관리자 키**만 입력 → 연결
- 키는 그 브라우저에만 저장됩니다. 공용 PC에서는 사용 후 **로그아웃** 하세요.

## 3. 누가 보이나요?
- 앱 첫 화면 **선생님께 진도 보내기** 카드에서 이름을 입력(동의)한 학습자만 보입니다.
- 이름을 입력하지 않은 학습자도 **자동 백업**은 되지만, 관리자 목록에는 나오지 않습니다.
- 관리자 페이지의 **삭제**는 목록에서만 숨깁니다. 학습자가 다시 공유를 켜면 다시 나타납니다.

## 저장되는 정보
| 항목 | 내용 |
|---|---|
| 진도 요약 | 카테고리별 학습·익힘 문장 수, Day 수, 연속 학습일, 최근 14일 학습량, 밀린 복습 수 |
| 설정 | 하루 분량, 학습 모드, 발음, 홈 화면 앱 사용 여부, 푸시 알림 여부 |
| 오류 | 학습자 기기에서 난 최근 오류 5건 (문제 파악용) |
| 백업 | 학습 기록 전체 — 관리자 페이지에는 나오지 않고, 학습자의 복구 코드로만 꺼낼 수 있음 |

이메일·전화번호 등 개인정보는 수집하지 않습니다. 이름은 학습자가 입력한 닉네임입니다.
