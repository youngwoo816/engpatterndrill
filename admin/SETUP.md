# 관리자 페이지 설정 (약 5분, 무료)

학습자들의 진도를 **내 Google 스프레드시트**에 모으고, `admin.html`에서 나만 볼 수 있게 연결하는 방법입니다.

## 1. 스프레드시트 + Apps Script 만들기
1. [Google Sheets](https://sheets.google.com)에서 **빈 스프레드시트**를 만들고 이름을 `Rep English 학습 기록`으로 바꿉니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 누릅니다.
3. 기본으로 있는 `Code.gs` 내용을 모두 지우고, 이 저장소의 `admin/apps-script.gs` 내용을 그대로 붙여 넣은 뒤 **저장**(디스크 아이콘)을 누릅니다.

## 2. 관리자 키 정하기
1. Apps Script 왼쪽 **⚙ 프로젝트 설정** → 맨 아래 **스크립트 속성 → 스크립트 속성 추가**
2. 속성: `ADMIN_KEY`, 값: 나만 아는 긴 문자열(예: 영문+숫자 20자 이상) → **저장**
   - 이 키는 관리자 페이지 로그인 비밀번호 역할입니다. 다른 사람에게 알려 주거나 저장소에 올리지 마세요.

## 3. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
2. 설정
   - 설명: `Rep English`
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**  ← 학습자들이 로그인 없이 기록을 보낼 수 있게 하는 설정입니다
3. **배포** → Google 계정 권한 승인(“고급 → 안전하지 않은 페이지로 이동”이 나오면 본인이 만든 스크립트이므로 진행)
4. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

## 4. 앱에 주소 넣기
- 저장소의 `config.js`에서 `syncUrl: ""` 따옴표 안에 웹 앱 URL을 넣고 `main` 브랜치에 커밋합니다.
  (Claude에게 URL을 알려 주면 대신 넣어 드립니다. URL은 비밀번호가 아니라 넣어도 안전합니다. 관리자 키는 넣지 마세요.)
- 1~2분 뒤부터 학습 앱 첫 화면에 **선생님께 학습 기록 보내기**(이름 입력) 카드가 나타납니다.

## 5. 관리자 페이지 열기
- 주소: `https://youngwoo816.github.io/engpatterndrill/admin.html` (앱 화면 어디에도 링크하지 않았습니다)
- 웹 앱 주소와 관리자 키를 입력 → **연결하고 불러오기**
- 키는 그 브라우저에만 저장됩니다. 공용 PC에서는 **로그아웃**을 누르세요.

## 보안·개인정보 메모
- 전송되는 정보: 학습자가 입력한 이름, 학습한 문장 수, 익힌 문장 수, Day 기록, 최근 14일 학습량, 카테고리별 진도, 앱 설정. 회상 입력 내용이나 녹음은 전송하지 않습니다.
- 학습자는 설정 → **학습 기록 공유**에서 언제든 전송을 끌 수 있습니다.
- 웹 앱 주소를 아는 사람은 기록을 **보낼** 수는 있지만, **조회**는 관리자 키가 있어야만 됩니다. 이상한 이름이 들어오면 관리자 페이지에서 삭제하세요.
- 원본 데이터는 스프레드시트 `learners` 시트에서도 직접 볼 수 있습니다.

## 코드를 수정해 다시 배포할 때
Apps Script를 고친 뒤에는 **배포 → 배포 관리 → 편집(연필) → 버전: 새 버전 → 배포**를 해야 반영됩니다. (URL은 그대로 유지됩니다)
